# TODOアプリ 要件メモ（学習用）

## 1. 目的

- pulumiを利用したIaCの学習
- ローカル → AWS（EC2 / S3 / CloudFront）移行を前提とした設計練習
- tRPC による型安全なAPI設計の習得

---

## 2. 前提条件

- 認証・認可：なし
- 利用者：単一ユーザー想定
- 初期環境：ローカル実行のみ
- 本番環境：将来的にAWSへデプロイ(Pulumi利用)

---

## 4. 機能要件

### 4.1 TODO管理（基本CRUD）

#### TODO項目

| 項目 | 内容 |
|---|---|
| id | UUID |
| title | タイトル（必須） |
| description | 詳細（任意） |
| status | todo / doing / done |
| dueDate | 期限（任意） |
| createdAt | 作成日時 |
| updatedAt | 更新日時 |

#### 操作
- TODO作成
- TODO一覧取得
- TODO詳細取得
- TODO更新
- TODO削除

---

### 4.2 状態管理

- 初期状態：`todo`
- `todo → doing → done`
- `done → doing` は可能（戻し可）

---

## 5. 非機能要件

### 5.1 バリデーション
- フロントエンド：Valibot
- バックエンド：tRPC input validation

### 5.2 エラーハンドリング
- 業務エラー（存在しないTODOなど）
- バリデーションエラー
- 予期しない例外
